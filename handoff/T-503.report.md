## Design and public API

```python
@dataclass(frozen=True)
class ThumbnailResult:
    path: Path
    size_bytes: int
    frame_time: float
    quality: int

class ThumbnailError(FfmpegError): ...
class MissingGlyphs(ThumbnailError):
    characters: tuple[str, ...]

def make_thumbnail(
    ffmpeg: Path | str,
    ffprobe: Path | str,
    video: Path | str,
    title: str,
    target: Path | str,
    *,
    subtitle: str = "",
    font: Path | str = DEFAULT_FONT,
    skip_seconds: float = 180,
    on_cancel: CancelHook | None = None,
) -> ThumbnailResult: ...

def read_cmap(font: Path | str) -> dict[int, int]: ...
def missing_glyphs(font: Path | str, text: str) -> tuple[str, ...]: ...
def wrap_title(text: str, *, width: int = 32, max_lines: int = 3) -> str: ...
def escape_filter_value(value: Path | str) -> str: ...
def choose_start(duration: float, skip_seconds: float, *, fps: float = 25) -> float: ...
```

- Uses existing `probe` and cancellable `run_ffmpeg`. After the requested skip, approximately
  two frames per second in a window of up to ten seconds are analysed at 160-pixel width with
  FFmpeg's `thumbnail` filter. A metadata file records the selected timestamp; the original
  source is decoded again at that time for the full-size output. `frame_time` is in source
  seconds. Videos shorter than the skip start halfway through; clips of at most two seconds
  use their middle frame, with a bound for a single-frame clip.
- Produces exactly 1280x720 with square pixels, aspect-preserving scale and black padding.
  The bundled DejaVu Sans Bold draws the title at 48 pixels over a dark translucent panel;
  the optional subtitle uses DejaVu Sans Regular at 28 pixels. A supplied custom font is used
  for both. Font advances bound wrapping width; Unicode character wrapping permits at most
  three title lines and one subtitle line, truncating with an ellipsis.
- Checks the original title and subtitle, then any added ellipsis, before rendering. The
  standard-library `struct` parser reads Unicode cmap format 12 preferentially, otherwise
  format 4, including range-offset/delta rules. Glyph zero is absent. Missing glyph errors
  identify each character and its Unicode code point; malformed fonts fail clearly.
- Title/subtitle content is stored in UTF-8 files, with `expansion=none`. Text never enters
  filter expressions. Paths are escaped at both FFmpeg parser levels; no shell is involved.
  On Windows, a non-ASCII font path uses its ASCII short-name alias to avoid FreeType silently
  substituting another font. The integration test compares its JPEG against an ASCII-path
  copy of the same font.
- Encodes JPEG at q=2, then 4, 6, 8, 12, 16, 20, 25 and 31 until strictly below 2,000,000 bytes.
  The result reports the encoder q value (larger means lower quality). Unique temporary text,
  timing and `.part` files live beside the target; `os.replace` publishes only a complete,
  size-checked JPEG. Errors/cancellation remove temporary files and retain an existing target.
- One caller cancellation callback tracks the currently running FFmpeg pass. It also handles
  cancellation before processing and between passes. Stopping raises `FfmpegCancelled`.

The cmap interpretation follows the [OpenType cmap specification](https://learn.microsoft.com/en-us/typography/opentype/spec/cmap).
Frame selection and literal text handling follow the official FFmpeg
[thumbnail](https://ffmpeg.org/ffmpeg-filters.html#thumbnail) and
[drawtext](https://ffmpeg.org/ffmpeg-filters.html#drawtext) documentation.

## Open questions and known limits

- No open questions for T-503.
- Frame analysis is bounded to the ten-second window after the selected skip, sampled at
  approximately 2 fps; it does not scan the entire lesson.
- The initial existing `probe` call is synchronous. Cancellation kills active FFmpeg passes
  and is checked around probing, but cannot interrupt ffprobe while that shared helper runs.
- On Windows, non-ASCII font paths need an ASCII short-name alias. If short names are disabled
  and no such alias exists, a clear error requests an ASCII font path, avoiding silent fallback.
- Font input supports ordinary sfnt TTF/OTF Unicode cmap formats 4/12, not TTC/WOFF collections,
  fallback fonts or variation sequences. Wrapping counts Python Unicode characters rather than
  grapheme clusters; bundled Armenian and Latin text is covered by tests.
