## Design

The page stays within its existing 1100 px maximum width. Background, panels and elevated
areas use the requested charcoal hierarchy. Primary actions are magenta; ordinary links use
soft pink, with pale pink hover. Mint is reserved for secondary actions, selected counts,
keyboard focus, selected text and upload progress. Armenian typography uses local
`"Segoe UI", "Noto Sans Armenian", Sylfaen, Arial, sans-serif`.

Functional colours are separate: lavender queued, blue running, yellow hold, orange retry,
coral failed, restrained leaf green done, and grey cancelled. Their existing Armenian labels
remain. Failed pills/badges use heavier text; done stays quiet. The cut bar stays blue for
kept sections and grey for removed sections, matching its unchanged Armenian explanation.

All controls have hover/focus styling. Disabled controls retain full opacity with readable
grey text. Reorder buttons keep their existing class and disabled behaviour. Progress tracks
have a contrasting outline, and file controls, date/select controls, video controls and
scrollbars inherit `color-scheme: dark`. Table containers also receive a keyboard focus ring.

## Computed text contrast

Ratios were calculated from sRGB channel values, without rounding before the pass/fail
comparison:

```text
c = channel / 255
linear(c) = c / 12.92                 when c <= 0.04045
            ((c + 0.055) / 1.055)^2.4 otherwise
L = 0.2126 * linear(r) + 0.7152 * linear(g) + 0.0722 * linear(b)
contrast = (max(L1, L2) + 0.05) / (min(L1, L2) + 0.05)
```

The table enumerates every authored text/background pair used by the templates and their
default, hover, focus and disabled styles. A headless Chrome audit of the actual isolated
pages found these same 30 unique pairs, including placeholders, file-button text and text
selection; **zero were below 4.5:1**. Foreground/background inheritance was resolved through
transparent ancestors to the first opaque surface. Native browser popovers and video-control
shadow content remain browser-rendered; their dark scheme is requested, but their internal
pixels are not represented as authored CSS colours.

Every text pair passes normal-text AA, including smaller table text; no large-text exemption
is needed. Primary labels are 16 px / weight 650. Their unrounded ratio is
**4.503294209626955:1**, which passes the actual 4.5 threshold.
