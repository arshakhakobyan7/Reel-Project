## What to build
`ClassroomPublisher(settings, tokens: AccessTokens | None, *, api_url, ...)` with
`publish(post: ClassroomPost, previous: dict | None, *, on_state=None, check=None) -> ClassroomResult`.
- `ClassroomPost`: job id, course id, video URL, and the template fields (`POST_FIELDS`).
- Text from `text_template`; the video goes in as a **link material** (`materials: [{link: {url}}]`),
  so Classroom shows it as a card. Post type from settings: an announcement, or a course-work
  material (with a title from the `title` field). Published state (`PUBLISHED`), never a draft that
  staff would have to publish by hand.
- **Idempotency:** with `previous` (stored post id + type) → patch that post (text / link) when it
  still exists; if it was deleted by a teacher → create a new one. Without `previous` → first look
  in the course's recent posts of that type for one whose link material has this video URL **or**
  a job marker you put in the text/description in a way that does not bother students (decide and
  explain); reuse it if found, otherwise create. One post per job across retries and crashes.
- **Re-run with a new video URL** (T-702 replaced the video): update the same post's link.
  Classroom cannot patch `materials` of an announcement — check the docs; if a field cannot be
  patched, replace the post (create the new one first, then delete the old one) and say so.
- Errors through `GoogleApiError` (403 `PERMISSION_DENIED` / course not found → permanent with a
  clear message: the account must be a teacher of that course); 401 → refresh once (client).
- **Dry-run:** no HTTP at all, no token needed; return the body that would be sent.
  Live mode with `tokens=None` or an empty course id → clear permanent error.
- `ClassroomResult`: post id, post type, `alternateLink` (the URL T-706 stores), created/updated,
  `dry_run`, `details` (no secrets).
