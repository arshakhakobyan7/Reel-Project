# Fonts

`DejaVuSans.ttf` and `DejaVuSans-Bold.ttf` from DejaVu Fonts 2.37 (covers Armenian and Latin),
used for thumbnail titles (T-503). Free licence (Bitstream Vera / public domain changes):
see `DejaVu-LICENSE.txt`.

Source: https://github.com/dejavu-fonts/dejavu-fonts/releases/download/version_2_37/dejavu-fonts-ttf-2.37.zip
(SHA-256 of the zip, computed on download 2026-11-19:
`7576310b219e04159d35ff61dd4a4ec4cdba4f35c00e002a136f00e96a908b0a`).

`Outfit-Bold.ttf` and `Outfit-SemiBold.ttf` from the Outfit project, used for the shared Reel
thumbnail card (T-1018). It is a free round geometric sans, close to Picsart's brand font Gilroy,
which is not free. SIL Open Font License 1.1: see `Outfit-OFL.txt`. It has no Armenian letters,
so Armenian text on the card is drawn with DejaVu Sans Bold.

Source: https://github.com/Outfitio/Outfit-Fonts, commit

- `Outfit-SemiBold.ttf`: `bf2e1d2a6ec2a67952e8b36edd2b2bb9f340c0cdd10b0ad5145b4dbbc1339608`
